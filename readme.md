# 💻 Currículo Interativo — Rafael Brandão

## 🚀 Sobre o Projeto

Este projeto consiste em um currículo profissional desenvolvido utilizando HTML5 e CSS3, com o objetivo de apresentar minha trajetória acadêmica, experiências profissionais, competências técnicas e projetos de forma organizada e interativa.

A página foi construída com foco na utilização de HTML semântico, na organização do conteúdo e na aplicação de estilos CSS para criar uma interface visual consistente e agradável.

## ✨ Principais Funcionalidades

- **Apresentação profissional:** resumo do perfil, área de atuação e objetivos profissionais.
- **Experiência profissional:** histórico de atuação em desenvolvimento e suporte de TI.
- **Formação acadêmica:** apresentação dos cursos e respectivos períodos.
- **Competências técnicas:** organização das habilidades em desenvolvimento, inteligência artificial, dados, cloud computing, infraestrutura e suporte.
- **Projetos:** apresentação de projetos desenvolvidos, com links para acesso.
- **Navegação interna:** links que direcionam o usuário às diferentes seções do currículo.
- **Informações de contato:** acesso rápido ao telefone, e-mail e perfil profissional no LinkedIn.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estruturação semântica do conteúdo e organização das seções da página.
- **CSS3:** estilização da interface, definição de cores, tipografia, espaçamentos e elementos visuais.
- **Google Fonts:** utilização das fontes Inter e Clarity City para a identidade visual do projeto.

## 🎨 Identidade Visual

O projeto utiliza uma paleta de cores baseada em tons de verde e creme, buscando transmitir uma aparência profissional e manter a consistência visual entre as seções.

- Verde-escuro: `#283618`
- Verde-oliva: `#606C38`
- Creme: `#FEFAE0`

## 📁 Estrutura do Projeto

Como o projeto utiliza uma estrutura simples, os arquivos ficam diretamente no diretório raiz.

```text
curriculo-interativo/
├── index.html
├── style.css
└── README.md
```

- `index.html`: contém a estrutura semântica e o conteúdo do currículo.
- `style.css`: reúne os estilos responsáveis pela apresentação visual da página.
- `README.md`: documentação e informações gerais sobre o projeto.

## ⚙️ Como Executar o Projeto

1. Clone ou baixe este repositório para sua máquina.
2. Abra a pasta do projeto em um editor de código, como o Visual Studio Code.
3. Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server para visualizar a página durante o desenvolvimento.

Não é necessária a instalação de dependências ou a configuração de um servidor back-end.

## 🎯 Objetivo de Aprendizado

Este projeto faz parte da minha evolução profissional na área de desenvolvimento web, permitindo colocar em prática conceitos de HTML semântico, CSS, organização de código e construção de interfaces.

A proposta é consolidar os fundamentos do desenvolvimento front-end por meio da criação de uma página funcional, acessível e organizada.
